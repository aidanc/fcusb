# End-user package

> Experimental and unofficial; no warranty, recovery or individual support is
> promised. Hardware damage and data loss are possible. Read [DISCLAIMER](../DISCLAIMER.md).

[Installation](INSTALLATION.md) is the canonical procedure. The single-file
setup and inspectable ZIP contain the same allowlisted project-only payload.
Both install the per-user manager; neither contains proprietary prerequisites.
See [release notes](RELEASE_NOTES.md) for availability and qualification.

Normal flow: Set up → risk acknowledgement → Adapter setup for both PIDs →
FlexColor with USB2Xchange. Use [daily use](DAILY_USE.md),
[troubleshooting](TROUBLESHOOTING.md) and [uninstall](UNINSTALL.md).
